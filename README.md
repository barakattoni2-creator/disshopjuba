# DIS Shop Pro - Next.js Storefront

Professional Amazon-style storefront for DIS Shop Juba.

## Included
- Next.js / React project, not only HTML
- Amazon-style customer homepage
- Destiny Investment & Supplies branding
- Brand sections: GREE, EMTOP, CLASS, LESSO, Schneider, Legrand, Spartan, Queen Sleep, Top Mattress, Royal Sleep
- Categories from DIS Shop business departments
- WhatsApp linked to +211923600599
- Email shown as info@disshopjuba.com
- Customer login / admin are planned placeholders for Firebase/Supabase integration

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy on Netlify
- Connect this folder to GitHub and Netlify
- Build command: npm run build
- Publish directory: .next

## Next step for real protection
Use Firebase or Supabase for:
- Customer authentication
- Admin role protection
- Orders database
- Email notifications to info@disshopjuba.com
- Product images and inventory management
